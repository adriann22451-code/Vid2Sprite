Parallax Layer ToolKembali ke toolDemo battle

Susun beberapa layer gambar (langit, gunung, pohon, tanah, dll) jadi background parallax untuk game 2D. Layer paling atas di daftar = paling belakang (bergerak paling lambat); paling bawah = paling depan (paling cepat).

Potong 1 gambar jadi beberapa layer

Upload satu gambar utuh (misal ilustrasi langit-gunung-pohon jadi satu file), lalu drag kotak di atas gambar untuk pilih satu bagian, kasih nama, dan tekan potong — bagian itu langsung jadi layer baru di bawah. Gambar sumber tetap ada supaya bisa dipotong berkali-kali (ulangi untuk tiap bagian).

+ Upload gambar sumber
Drag di gambar buat pilih area dulu.

Layer

Tiap layer: Speed 0 = diam (misal matahari/langit jauh), 1 = ikut kecepatan kamera penuh (layer paling depan biasanya di atas 1) — makin dekat/depan, makin cepat geraknya. Tinggi = persentase tinggi kanvas. Posisi Y 0% = nempel atas, 100% = nempel bawah. Posisi X cuma berlaku kalau Ulangi dimatikan — 0% nempel kiri, 100% nempel kanan, dipakai buat naruh potongan objek spesifik pas di tempat asalnya. Ulangi = di-tile horizontal supaya scroll tanpa putus (matikan untuk elemen unik seperti satu bangunan/potongan objek).

Ekspor
