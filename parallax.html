Parallax Layer ToolKembali ke toolDemo battle

Susun beberapa layer gambar (langit, gunung, pohon, tanah, dll) jadi background parallax untuk game 2D. Layer paling atas di daftar = paling belakang (bergerak paling lambat); paling bawah = paling depan (paling cepat).

Layer

Tiap layer: Speed 0 = diam (misal matahari/langit jauh), 1 = ikut kecepatan kamera penuh (layer paling depan biasanya di atas 1). Tinggi = persentase tinggi kanvas. Posisi Y 0% = nempel atas, 100% = nempel bawah. Ulangi = di-tile horizontal supaya scroll tanpa putus (matikan untuk elemen unik seperti satu bangunan).

+ Tambah layer (gambar)

Ekspor

ZIP berisi PNG tiap layer (sudah diberi nomor urut), layers.json (metadata untuk dipakai ulang di engine/kode kamu), dan satu file preview.html mandiri yang bisa langsung dibuka di browser.
